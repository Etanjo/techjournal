## Goal:
The goal of this lab was to use packet tracer to understand how routers operate, as well as layer 2 protocols. It also aims to help us understand default gateways.

## Useful Instructions:
When you make an empty router you must first turn off the router before putting the proper ports in. Once they are in you can turn on the router again. This can all be done in the physical tab. Once ports are connected, make sure they are enabled in the config tab

## Problems:
I ran into an issue where my switches were connected incorrectly on the router. A useful setting to check for this is always show port labels in the interface section of the preferences part of the settings.

## Questions:
Beyond the physical wire connection to the router, the pcs must first go through the default gateway, which is the switch's connection to the router. In order to get the proper mac address for the default gateway, it must first ARP for it.  The PC must have the proper default gateway set in its config tab.
