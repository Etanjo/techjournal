## Goal
The goal of this lab was to use packet tracer to set up wireless access points to the internet, and how to connect devices to this network.

## Useful Instructions:
In order to setup the wireless router, you must first go into the GUI tab and go to setup. Then switch the internet connection tupe to static IP. With the internet IP given, input that information in the boxes in the internet setup section. Do the same for the network setup section, turn on DHCP server. Make sure to scroll down and save. Then go to the wireless tab, switch network mode to Wireless-N Only and name the router whatever you want (remember it). Turn off SSID Broadcast, then scroll down and save. Then go to wireless security and switch the security mode to WPA2 Personal, and enter a passphrase (remember this as well). In order to connect the devices to the network, go to the devices, desktop, pc wireless. Go to profiles, and go to new. Name this new profile whatever (in this case Wireless Access). Go to advanced setup, type in the name of the wireless router and hit next. Hit next again, switch security to match the wireless router, hit next and enter the passkey. Hit next and then hit connect to network. When connecting the wireless router and the server to the regular router, make sure that the port on the router has the same ip as the default gateway of the device you're trying to connect to.
