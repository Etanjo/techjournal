## Goal:
The goal of this lab was to use packet tracer to build and gain an understanding of VLANs (Virtual Local Access Networks).

## Useful Instructions:
In order to create VLANs you must (on each switch on each layer of the VLAN) you must go into the switch config tab. The first step is to type in the name and number of the VLAN into the dedicated boxes, then click add. Repeat for each VLAN. Then you must go to each fast ethernet port you will be using, go to the VLAN dropdown and click the specific VLAN that you want that port to connect to. They need to be set as access, but they should be set that way by default. Then for each gigabit internet port you will be using, switch them to be trunks so that they can send information to other switches. Make sure the proper VLANs are selected, but they should all be checked automatically.
