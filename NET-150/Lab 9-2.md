## Goal:
The goal of this lab was to use packet tracer to understand how ospf routing works.

## Useful Instructions:
The most useful instructions were how to setup ospf routing. On each router open the config terminal cli. Then type router ospf. After that, for each network connected directly, type "network x y area z" where x is the ip, y is the subnet mask of the network in terms of network bits an NOT host bits. z is the number of the area the network is in. You can use show ip route ospf neighbor to see a neighboring network an show ip route ospf to show the opsf routes with costs.
